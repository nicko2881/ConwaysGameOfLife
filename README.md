# Conway's Game of Life

This project was created for a programming class.  
It implements Conway's Game of Life, a cellular automaton simulation that evolves through multiple generations according to predefined rules.

## Features

- Grid-based simulation
- Custom initial states
- Generation progression
- Rule-based cell evolution

## Technologies Used

- Java 17
- Git

## Future Improvements

- Graphical user interface
- Adjustable simulation speed
- Save and load patterns
- Custom grid sizes
